# Priama

Priama is a local-first desktop writing application for authors. It works fully offline and stores projects as portable files on your Mac.

## Download for Apple Silicon

[Download the latest Priama installer](https://github.com/andyrpr/priama/releases/latest)

Priama currently supports Apple Silicon Macs (M1, M2, M3, M4, and newer).

## Install

1. Download the `.dmg` from the latest release.
2. Open it and drag Priama into Applications.
3. Because the current build is not Apple-signed, right-click Priama in Applications and choose **Open** the first time.

Priama does not require an account and does not upload your writing.
